# Направление развития

Trident CLI — локальный инструмент для личного использования. Его задача — делать метод доступным через обычный терминал и хранить записи в переносимой базе SQLite.

## Основа

- Кайрос: записи о событиях, действиях и решениях.
- Хронос: до шести открытых датированных задач на Тридент-день.
- Андерлайн: плавающие задачи без дневного лимита.
- Айон: список идей с переносом в план.
- Атрибуты: STR, AGI, INT и отдельный WILL.
- Медленный подсчёт: закрытие дней, 28-дневные сезоны и накопленная база.

## Текущий CLI

Поддерживаются журнал, план и задачи, идеи, дневные и сезонные отчёты, история, экспорт JSON/CSV, настройки часового пояса и диагностика локального окружения.

## Направление работы

- Упростить установку и справку для нового пользователя.
- Сохранять записи при обновлениях схемы.
- Улучшать резервное копирование и экспорт данных.
- Держать команды пригодными для терминала и скриптов.
