# Инструкции для trident-cli

## Среда

- Python 3.11 или новее; runtime использует только стандартную библиотеку.
- Команды читают и изменяют локальную базу SQLite.
- Вывод результата идёт в stdout; ошибки и диагностика — в stderr.
- Текущее время получать через trident_cli.clock.now().
- Изменения схемы оформлять новой нумерованной миграцией в trident_cli/storage/migrations.py.
- Не помещать пользовательские записи или секреты в репозиторий.

## Продуктовые правила

- Не добавлять фоновые задачи и уведомления.
- Не использовать штрафы, проценты выполнения или формулировки о провале дня.
- WILL показывать отдельно от STR, AGI и INT.
- Сохранять ясные локальные команды и JSON-вывод для команд чтения.

## Проверка изменений

- Перед завершением запускать python -m pytest.
- Не добавлять runtime-зависимости.
- Сохранять нейтральные формулировки: план помогает, но не оценивает человека.
