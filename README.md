# Trident CLI

Локальный CLI для ведения Тридента: записей о прожитом, плана на день, списка идей и учёта усилий. Данные хранятся в SQLite на вашем компьютере.

## Система

| Часть | Для чего |
|---|---|
| Кайрос | Записывать важные события, действия и решения по мере необходимости. |
| Хронос | Планировать до шести главных открытых задач на конкретный Тридент-день. Порядок задач произвольный. |
| Андерлайн | Держать менее важные задачи под чертой. Они не занимают места в дневном лимите и не привязаны к дате. |
| Айон | Хранить идеи «может быть, когда-нибудь» и переносить выбранные в Хронос. |
| Атрибуты | Отмечать усилие по STR, AGI и INT. WILL записывается отдельно как внутреннее сопротивление. |

Для каждой оси можно указать от 1 до 3. Если усилие по оси не требовалось, её можно не указывать: это ноль. Отрицательных значений нет.

CLI закрывает Тридент-день по настроенной границе дня и считает накопления по 28-дневным сезонам. Дневные очки переводятся по правилу 10:1 с округлением вверх; при закрытии сезона его результат добавляется к накопленной базе. WILL всегда показывается отдельно от STR, AGI и INT.

## Установка

Нужен Python 3.11 или новее. Из папки проекта выполните:

    python -m pip install .
    trident --help

Если команда trident не появилась в PATH, CLI можно запускать так:

    python -m trident_cli --help

## Короткий ежедневный цикл

Запишите событие или принятое решение:

    trident log "Подготовил план и решил начать с черновика" +2 INT +1 WILL

Посмотрите записи за день:

    trident day

Добавьте главные задачи и менее важные дела:

    trident task add "Закончить черновик"
    trident task add "Позвонить врачу"
    trident task add --underline "Разобрать заметки"

Покажите план:

    trident task list

Завершите задачу. Это также создаст запись в Кайросе:

    trident done 1 +2 INT +1 WILL

Если задачу больше не нужно делать, отпустите её:

    trident refuse 2

Перенесите открытую задачу в Айон:

    trident task later 3

В задаче можно указать дату, заметку, время напоминания, флаг «лягушка», ссылку на Epic или Sprint и шаги:

    trident task add --date 2026-10-15 --note "Сначала набросок" --frog "Подготовить доклад"
    trident task step add 4 "Собрать материалы"
    trident task step done 4 1

Время напоминания хранится как поле задачи. CLI не отправляет уведомления.

## Идеи в Айоне

Добавьте идею, покажите список и перенесите выбранную в план:

    trident aion add "Научиться ходить под парусом" --why "Хочу попробовать"
    trident aion list
    trident aion pull 1

Список Айона показывается от старых идей к новым. Ненужную идею можно убрать командой trident aion drop ID.

## Просмотр и настройки

    trident season
    trident history --since 7d
    trident export --format csv --output journal.csv
    trident doctor
    trident config set timezone Europe/Moscow
    trident config set day_open_hour 10

Граница дня по умолчанию — 10:00. Часовой пояс и время границы можно настроить отдельно. Любая команда чтения поддерживает --json; справка доступна через --help.

По умолчанию база находится в системной папке данных пользователя: в Windows — в %APPDATA%	rident-cli, в Linux — в $XDG_DATA_HOME/trident-cli или ~/.local/share/trident-cli. Переменная TRIDENT_HOME задаёт другой каталог.
